# Test Suite Value Audit - Findings Report (Issue #249, umbrella #246)

## Scope examined

All 752 tracked test modules: `ps-service/tests` (725), `ps-cli/tests` (25), `ps-test-support/tests` (2). Per-module classification: `docs/audits/test-value-audit-modules.md` (generated by `classify.py`, totals keep 745, merge 0, rewrite 7, remove 0). Tests run by default: 8051 passed, 1 skipped (8625 collected, 573 deselected by the six environment-dependent markers).

Expected delta: two tests are removed (T-001, T-006) and fourteen test cases are added by strengthening existing tests (T-018: 10 parametrised manifest cases, 1 intake-validation case, 3 live-marker cases), so the final run reports 8063 passed, 1 skipped.

## Method and commands

Removal rules: R1 exact duplicate (same normalised AST, same fixtures, and the survivor covers the removed test's stated scenario); R1b if names or docstrings claim distinct requirements the pair is kept and filed, never silently removed; R2 cannot fail; R3 tests removed code. Every removal batch needs a witness: a one-line fault injected into a scratch copy of the code under test that the surviving test fails on.

| Step                    | Command                                                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Duplicates              | `uv run python .orchestrator/tracker/i249/tools/dupes.py ps-service/tests ps-cli/tests ps-test-support/tests`               |
| Weak assertions         | `uv run python .orchestrator/tracker/i249/tools/weak.py ps-service/tests ps-cli/tests ps-test-support/tests`                |
| Mock boundary staleness | `uv run python .orchestrator/tracker/i249/tools/boundaries.py`                                                              |
| Baseline run            | `uv run pytest --cov --cov-branch --durations=40` on the unchanged tree (log `baseline_full.log`)                           |
| Mutation sample         | `mutmut` 3.x in a scratch copy outside the repository (`ps_service` copied, `pythonpath` set, `ps_service.__file__` checked) |
| Flakiness               | per file: 3 serial runs, 1 reversed order (scratch `reverse_order` plugin), 1 `-n2` run                                     |

## Severity scale

High: a test that protects nothing and hides a regression. Medium: duplicated or weak coverage that misleads. Low: hygiene.

## False positives and reasons

- `boundaries.py` reports `llm: litellm.completion/embedding` and `falkordb: export.falkordb_connection.raw_connection` as DEAD because it imports a dotted attribute chain; references exist (4, 3 and 1).
- `boundaries.py` reports `_CURATED_CONTENT_DIR`, `_DEFAULT_RECORDS_DIR`, `_DEFAULT_REPORT_PATH` with zero references because the tool modules live in dashed directories; `grep` finds them patched or asserted in `test_curated_content_capability_loader.py` and `test_exclusion_audit_cli.py`.
- `weak.py` labels tests NOASSERT when the assertion sits inside a helper (`run_deploy(..., expect=0)` and similar); T-011.
- Hash-equal pairs in different files (T-003, T-004) are not duplicates: each tests a different module.
