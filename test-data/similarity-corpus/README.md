# Similarity corpus

Frozen `baseline.json` exports of GDPR, NIS2 and CRA, used only by
`tools/company-merge/company_merge_similarity_sweep.py` and its tests.

The sweep's labeled pairs cite capability ids that exist in exactly these files. Curated
content is regenerated by LLM ingestion and is not reproducible, so the corpus is kept here
unchanged and is not part of the curated catalog. Do not regenerate or edit these files:
doing so invalidates the labeled dataset.
